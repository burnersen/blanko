## blanko (blanko.burnersen.de)

Unter blanko.burnersen.de biete ich den Papier-Generator „blanko“ an. Das Papier (Vorschau und PDF) entsteht vollständig in deinem Browser. Es werden dabei keine Inhalte, Einstellungen oder sonstigen Daten an meinen Server oder an Dritte übertragen.

**Server-Logdateien.** Beim Aufruf der Seite speichert mein Hosting-Anbieter [Name des Hosters] automatisch die üblichen Zugriffsdaten (IP-Adresse, Datum und Uhrzeit, aufgerufene Adresse, Browser und Betriebssystem). Das ist technisch nötig, um die Seite auszuliefern und vor Missbrauch zu schützen. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Die Daten werden nach [Speicherdauer laut Hoster, z. B. 7 Tagen] gelöscht.

**Speicherung auf deinem Gerät.** blanko legt keine Cookies an und verwendet kein Tracking und keine Analyse-Werkzeuge. Damit die App ohne Internet funktioniert, speichert dein Browser die Programmdateien in seinem Zwischenspeicher (Service Worker). Wenn du Favoriten, „Meine Blätter“ oder die Darstellung (hell/dunkel, Farbe) nutzt, werden diese Angaben im lokalen Speicher deines Browsers (localStorage) abgelegt. Sie verlassen dein Gerät nicht. Diese Speicherung ist für die von dir ausdrücklich gewünschten Funktionen unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Du kannst sie jederzeit löschen, indem du die Websitedaten von blanko.burnersen.de in deinem Browser entfernst.

**Updates.** Der Server von blanko fragt regelmäßig bei GitHub nach, ob es eine neue Version gibt. Dabei werden keine Daten von Besucherinnen und Besuchern übermittelt.

**Externe Links.** blanko enthält Links zu anderen Seiten (zum Beispiel suchsel.burnersen.de, kaufen.burnersen.de, GitHub und Ko-fi). Erst wenn du einen solchen Link anklickst, wird die jeweilige Seite aufgerufen. Dort gelten deren Datenschutzbestimmungen.
